## 默认值与结论

首次启动 A/B/C 三组均勾选。保存过启动配置则保留上次保存值。

| 组 | 默认行为 | 原因 |
|---|---|---|
| A 左侧 | TCP XYZ = (290.179716, -21.103831, 22.065103) mm | 左侧独立验证 RMS 9.229 -> 7.349 mm，部分改善的试验候选 |
| A 右侧 | TCP XYZ = (269.275904, 25.160820, 28.126456) mm | 保留原值；右候选独立验证 11.460 -> 13.075 mm，变差 |
| B | bias = 0 mm、scale = 1 | 约 9 mm RGB—深度偏差不是已识别的修正参数 |
| C | 本轮相机 XYZ、候选旋转，旋转增量为 0 | 12 fit / 6 validation；验证平移 RMS 11.717 -> 5.591 mm，仍非绝对精度认证 |

A 并非禁止使用；右侧若要做明确的候选对照，可手动填入
`(257.447952, 16.765031, 13.959216)` mm。该组在已有验证中表现更差，不作为默认值。
关闭 A 使用当前原模型的 TCP；关闭 B 不改深度；关闭 C 使用原名义相机变换。
所有候选均不覆盖官方 URDF，不自动改变手型或发送运动命令。

## 参数含义

- A：所选侧 wrist_yaw_link 坐标系中的 TCP **绝对位置**，不是 pelvis 方向的目标偏移；TCP 旋转保持模型值。
- B：在 RGB 光学坐标系沿像素射线修正深度：`z_new = scale*z_old + bias_mm/1000`，
  XYZ 同乘 `z_new/z_old`。正 bias 增大距离；非正深度拒绝，不补造有效值。
  bias 范围 ±30 mm、scale 0.95～1.05 是界面输入限制，不是已验证安全工作区。
- C：XYZ 为相机在 torso_link 中的绝对位置，单位 mm。旋转项为相对 C 候选、绕 torso
  固定轴的增量，单位度；组合 `Rz(dz) Ry(dy) Rx(dx) R_candidate`。不存在第二份相机 TF。
- 目标点、碰撞点云与 RViz 点云应用相同 B/C 修正。原始归档不覆盖；计划 geometry 内记录
  名义与生效变换、完整参数和参数摘要。
- 规划及 center check 的有效 TCP 与 A 一致；结果保留原模型 FK 作对照。
  `fk_error_mm` 仍是编码器计算值，不是尺子测量。

## 测试流程

1. 默认全勾选可做首轮计划；先检查目标、点云和轨迹，按原确认步骤执行 center check。
2. 等到位后用尺子测量真实指尖相对**抬高后的 check 目标**的偏差，不要把预设高度当误差。
3. 调参页点击“记录尺测误差”，选择该次已到位的 `center_check_result.json`，
   填写 pelvis XYZ 下“真实指尖位置减目标位置”的毫米差及备注。
   保存到该记录旁的 `ruler_*.json`，绑定原结果 SHA、当时参数和目标，不自动修正配置。
4. 一次只改一组，再重新 Plan / Execute；不要沿用旧计划。
5. 对照不止一个目标位置/腕姿态，避免用多组参数相互抵消一个位置的误差。
6. “保存为启动配置”写入 `config/task_calibration.json`；可编辑、关闭单组，或恢复本轮初值。

参数修改会作废旧计划和轨迹预览；规划/执行/关闭期间禁止修改。执行前再次比对参数快照。
旧保存轨迹不能套新补偿执行；参数不一致会拒绝加载，需重规划或恢复同一配置。
没有补偿记录的历史轨迹仅允许在三组都关闭时加载。保护、STOP、速度和确认流程不放宽。
TCP 补偿没有重新测量手部碰撞外形，不能理解成完整碰撞或安全验收。

## 是否重做 A/B

目前无需为了试验调参重采整轮。A 左侧可以对照，右侧先用原值；若要把右 A 当作
稳定的自动校正，需要重新检查固定触点、姿态和独立验证。B 若要得到可靠的非零偏置/比例，
需在不同距离/位置/倾角上验证模型，不能仅凭一个位置尺测推出全局深度修正。

## 一秒深度平均

本版尚未实现多帧采集平均。它应是独立于偏置/比例的可选降噪步骤：场景与相机静止，
忽略 0/无效深度，保留有效计数和源帧，RGB、目标及点云使用同一归档结果。
平均不能消除固定偏差或保证修复固定形变；运动会造成拖影，不能拿旧平均图继续规划。
这项需要机载相机服务后续改动和实机验证，本次充电期间没有部署。
