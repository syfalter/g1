# 圆心定位标定面板

启动：

```bash
bash /home/syf/g1_upper_body_ws/scripts/start_center_calibration.sh
```

关闭窗口即可退出，不影响任务面板、控制器或 RViz。本面板没有 ROS / DDS 连接，不规划、不执行、不写入机器人参数。

## 记录

1. 在原任务面板完成一次 Center check，到位后量取固定实体点的位置。
2. 在标定面板刷新记录，选择对应的 session / plan。
3. 输入前后偏差（前正、后负）、左右偏差（左正、右负）、距圆心表面的实际高度（上正、下负），全部使用毫米。方向以固定初始机器人方向为准，不随转腰改变。
4. 点击固定在窗口底部的绿色“保存新样本”。每次成功保存都追加一条，绝不按 plan 覆盖。同一 plan 可记录多次测量；保存后清空数值，避免重复点击误录。输入为空时刷新会选最新到位记录，存在未保存输入时保留原选择。
5. 要修改原数据，先在表格明确选中样本，修改数值后点独立的“修改选中样本”。规划关联选错也可在此选择正确 plan 后修改。此按钮不会新增样本，修改前保存历史版本。
6. 留出部分新位置，将用途设为“独立验证”；有明确测量失误的样本可以设为“排除”。不自动删除异常点。同一 plan 的重复测量不等于独立新位置验证。
7. 点击计算补偿保存报告；CSV 可选择路径导出。

第一轮可填写前后 35、左右 0、实际高度 35。左右 0 只是“小偏差”的近似，建议备注“目测估计”，精确测量后更新。程序不会自动把这组口述近似值作为正式样本。

测量点必须固定，例如食指末端中心；不能一轮量指腹、一轮量最尖端。实际高度参考面需要对应检测到的圆心表面，不是桌面。更换手臂、实体点、相机安装、手部安装或机器人基座位置后应分开建数据集，避免混合拟合。

## 计算

- 实测偏差 = [前后偏差, 左右偏差, 实际高度 − 本次目标高度]。
- 几何残差 = 实测偏差 − 本次关节反馈 FK 偏差。
- 固定偏移估计 = 参与拟合样本的几何残差均值。
- 建议目标补偿 = 固定偏移估计的相反数。
- 逐点残差、3D RMS 和最大残差反映该固定偏移对样本的解释程度；独立验证样本不参与求均值。

这是固定偏移的初步拟合，不能单独辨识相机外参与指尖变换，也没有辨识姿态相关误差。只有一个点时拟合残差为零是数学结果，不代表标定准确。补偿后的残差是离线预测，不是真机补偿后的实测精度。

## 文件

- 自动保存样本：`data/center_calibration/measurements.json`
- 覆盖数据文件前自动备份原版本：`data/center_calibration/measurements_history/`，包括修改和删除前的完整样本。
- v2格式每条测量都有独立sample_id；读取旧v1文件自动迁移内存格式，原文件在下一次写入前会备份。历史备份仅能保护升级后的操作，不能恢复旧版已经覆盖的实测值。
- 点击计算后保存：`data/center_calibration/measurements_fit.json`
- 样本包含原始实测数据、到位反馈与几何快照、原始记录路径及 SHA256；删除原始 session 后已保存样本仍可读取。
- 计算报告嵌入计算当时的完整样本，后续修改样本后再次点击计算才更新磁盘报告。
- 文件采用原子替换；同一数据文件只允许一个面板进程打开。损坏文件不会被静默清空覆盖。
- 写入前比对磁盘版本，其他窗口或外部程序改过文件时拒绝覆盖。不要继续用已经运行的旧版本窗口保存，关闭标定窗口并重开加载新版即可，不需要退出任务面板。

新建独立数据集可以指定文件：

```bash
bash /home/syf/g1_upper_body_ws/scripts/start_center_calibration.sh --data /home/syf/g1_upper_body_ws/data/center_calibration/setup_02.json
```
