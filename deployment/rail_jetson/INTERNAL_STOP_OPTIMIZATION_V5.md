# 内部停顿诊断与 V5 离线候选

## 定位

用户当前播放的 V4 起落架组合确有内部停顿，不只是 RViz 卡顿。
`entry_lower` 从准备位到下杆位为 9.48311245 秒，内部存在 7 个低速谷。
旧的时间域平顺拟合跟随录制/编辑时间轴，不能保证解除被删除片段边界
留下的停稳趋势。连续加速度或较小 jerk 跳变，也不等于速度不接近零。

V5 在同一段上得到 6.076703299 秒，内部低速谷为 0。关节速度范数
低于 0.015 rad/s 的累计时间由 2.040 秒降到 0.125 秒；该统计排除起止
各 0.15 秒，剩余低速不等于出现一次内部停顿。

使用食指 TCP 的解析雅可比速度另行检查，旧段 7 处内部谷低于 2 mm/s，
新段没有此类谷；排除起止各 0.15 秒后，TCP 速度低于 1 mm/s 的累计
时间由 1.118 秒降为 0。谷值检测采样约 2 ms，不是物理测量或最低
TCP 速度的连续数学证明。

## 算法

实现位于 `scripts/task_stop_blending.py`，只用于离线候选。

1. 从相同 jerk 策略下、保留原路径的调速结果重新开始，不重复花费 V4
   已使用的路径偏差预算。为前序调速数值误差预留每关节 1e-7 rad。
2. 搜索内部近零速谷及前后正常运动区间。保留业务单元端点和独立手指
   等待，不把端点停稳或握放等待当作内部缺陷。
3. 在局部窗口内构造七次 Hermite 过渡，匹配两侧位置、速度、加速度
   和 jerk。搜索不同宽度、左右偏移及持续时间；拒绝两侧速度方向相反
   的窗口，不强制把真正换向改为非零速。
4. 用有序弧长对应建立新旧曲线的单调对应关系，再对对应关系每个区间
   使用 Bernstein 多项式界检查完整连续曲线偏差，而不是只比较采样点。
   接近/退出默认 5 mm、接触/未明确分类默认 1 mm；关节及姿态预算
   同时检查，混合窗口采用严格预算。
5. 局部过渡直接通过最终 V/A/J 限制才入选，不对整条轨迹降速来迁就
   不合格局部。对速度范数平方求导并求内部极值，排除过渡自身再次
   掉到近零速的候选。
6. 输出仍是现有五次插值协议。自适应细分同时控制位置、速度、加速度
   和 jerk 的插值误差，而不只控制位置误差。整个最终单元再次校验
   关节限位、腰部包络及连续多项式 V/A/J。
7. 若还剩路径预算，再尝试全单元 C4 正则化平顺；只有不重新增加低速谷、
   满足剩余几何预算和时长约束才采用。否则保留局部改进版。
8. 无合格改进时保留原候选，报告原因。选型不允许增加检测到的内部
   低速谷数量，也不宣称找到全局时间最优。

拉环组合按 `entry / cycle / final` 缓存优化单元，将左拨衔接和右拨
放到同一个单元内检查，避免把右拨入口固定当作必须停稳的分段边界。
循环单元之间的端点仍保持可独立复用的停稳接口，不宣称全任务无停顿。

## 同配置结果

以下均为 jerk=5 软件策略、速度倍率 1。组合与原固定预览使用相同
录制版本和组合条件。低速谷按实际选用单元统计，不包含业务等待及
单元端点；重复使用单元按使用次数计数。

| 任务 | V4 秒 | V5 秒 | 内部低速谷 |
| --- | ---: | ---: | ---: |
| 准备位至下杆位（组合接近单元） | 9.483 | 6.077 | 7 -> 0 |
| 起落架组合 | 68.465 | 55.523 | 32 -> 8 |
| 拉环左拨右拨组合 | 82.883 | 74.605 | 21 -> 8 |
| 单独左拨 v7 | 40.207 | 43.894 | 3 -> 0 |
| 单独右拨 v1 | 40.844 | 36.056 | 15 -> 5 |
| 起落架接近上杆 v4 | 11.182 | 8.960 | 6 -> 0 |
| 滑轨接近 A v3 | 11.889 | 9.688 | 4 -> 0 |
| 滑轨接近 B v2 | 29.379 | 26.941 | 4 -> 2 |

单独左拨变慢了，不能把本轮报告成全部提速。单独 `above_to_lower` v6
在原已选候选中没有检测到目标低速谷，因此保持 6.659 秒；它不是组合
中的 `entry_lower`，后者还包含准备位衔接和下杆对接。

部分 V5 单元未通过剩余预算内的全局 C4 平顺，会保留原调速器在局部
替换区间之外的 jerk 跳变。它们的 jerk 幅值仍通过上限检查，但不能
称为全局 jerk 连续，也可能在高频平顺度指标上不如 V4。保留 V4 对比
选项，用户可比较“去停顿”和“全局平顺”的实际差别。

所有 14 个当前选中单段和两个组合均运行本方法。未消除的低速谷、
拒绝原因、各处连续偏差界及最终限值验证保存在：

`data/composition_candidates/*-v5-extra0.15-flow.json`

完整对照指标在同名前缀的 `-evidence.json`。这些是离线数据，不是
机器人实测，jerk=5 仍不是已证实的电机物理上限。

## 面板

固定预览保留原路径、最快择优、V4 平顺版及新增的“连续通行 · V5
内部去停顿”。选择任务自动加载，默认播放 V5，无需重新生成。
“最大额外时长”仍是相对最快候选的准入预算，不保证每个任务都提速。
接近段约 6.08 秒包含在起落架组合总时长约 55.52 秒内，不要混比两者。

本轮不修改录制选择、生产限值、真实控制器或 Jetson，不产生硬件命令。
