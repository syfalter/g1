# 示教去抖与平顺调速：V4 调研与实现

调研日期：2026-09-27。仅离线候选，不修改生产限值、不推送真机。

## 问题判断

单次示教不能唯一确定操作者理想中的路径。可以估计的是：在给定几何
容差、业务端点和运动先验条件下，更可能表达原操作意图的平滑曲线。
不能未经标注就把真实接触、换向或避障动作当成噪声删除。

本地诊断也说明，不是所有 jerk 毛刺都来自手抖。完整右拨 v9 的调速前
拟合曲线在内部连接处的 jerk 跳变约为数值误差量级；V3 的 jerk=5 候选
有 271 个内部连接处的 jerk 跳变量超过 1 rad/s^3。分段时钟和最终插值
同样需要处理。该计数不是原始示教抖动点数。

## 一手资料与取舍

### 正则化平滑样条

SciPy 官方 `make_smoothing_spline` 文档给出加权拟合残差加平滑惩罚的
目标，并支持用 GCV 选正则强度。该现成接口是三次样条、二阶导惩罚，
并不直接提供本任务所需的 jerk 连续性、业务端点和路径偏差认证。

采用其正则化思想，用现有 SciPy `BSpline` 与稀疏线性求解器构造五次
样条，加入三、四阶导惩罚。没有升级本地 SciPy，也没有假定本机具备
新版 `make_smoothing_spline` 接口。

资料：
```text
https://docs.scipy.org/doc/scipy/reference/generated/scipy.interpolate.make_smoothing_spline.html
```

### 稳健拟合

SciPy 官方 `least_squares` 文档说明 `soft_l1`、Huber 等损失用于降低
离群残差的影响。V4 用 soft-L1 型迭代重加权，减少孤立偏移对整体曲线
的牵引。残差尺度使用 MAD 估计及数值下限；它是拟合启发式参数，不是
传感器经过标定的噪声标准差，也不代表电机能力。

稳健损失不是豁免几何限制：降权后的点附近仍必须通过连续偏差检查。
业务起终点不参与降权，位置保留，速度和加速度为零。

资料：
```text
https://docs.scipy.org/doc/scipy/reference/generated/scipy.optimize.least_squares.html
```

### Savitzky-Golay 滤波

SciPy 官方接口提供局部多项式窗口滤波与导数估计。它适合做示教数据
诊断或初步去噪，但单独调用这个滤波器并不构成本项目的连续路径偏差、
关节限位、最终 V/A/J 或拼接连续性证明。因此不把滤波采样点直接作为
真机轨迹，也不将其作为本轮主要输出算法。

资料：
```text
https://docs.scipy.org/doc/scipy/reference/generated/scipy.signal.savgol_filter.html
```

### Ruckig

Ruckig 作者仓库描述的是给定状态与运动限值下的轨迹生成；限 jerk 与
估计含噪示教背后的理想路径是不同问题。仓库还说明 Community 版本的
中间路点计算使用云服务，因此本轮不引入这条途径，也不上传录制数据。
原有项目中已经使用的规划接口不受本轮改动影响。

资料：
```text
https://raw.githubusercontent.com/pantor/ruckig/main/README.md
```

检索工具本轮没有返回可引用页面，以上官方资料通过直接 HTTPS 获取并
核对正文。尝试获取 Flash/Hogan 原文页面被 403 拒绝，因此未把未读到
的原文当作本轮实现或效果的证据。

## V4 实现

代码：`scripts/task_smooth_timing.py`。

1. 以同 jerk 策略的原路径调速结果为参考，避免把 V3 已经花掉的几何
   容差再次使用。参考仍然只是拟合的录制路径，不是真实物体位置。
2. 对整业务单元拟合五次 B 样条；在数据贴合项之外，加入积分平方 jerk
   和积分平方 snap（jerk 的变化率）惩罚，使用稳健重加权。
3. 保留业务起终点，端点速度、加速度、jerk 均为零。普通内部结点采用
   单结点五次样条，理想计算下具有 C4 连续性。必要的握紧、松开、换向
   业务边界仍然保留，而不是把整个任务无条件平滑过去。
4. 搜索多个结点间距与正则尺度。源曲线和候选曲线的所有分段边界取并集，
   用 Bernstein 连续界约束关节、TCP 位置和姿态差异，不只检查采样点。
5. 满足偏差约束后只进行统一时间缩放，检查最终输出多项式的 V/A/J、
   关节位置、腰部包络、内部 jerk 跳变和端点 jerk。不会再调用 V3 的
   分段局部时间扭曲来破坏连续性。
6. 默认相对 V3 最快单元最多增加 15% 时长，可在面板调整。按平顺度与
   时间共同评分。没有合格结果时明确回退并显示通过单元数，不伪装成
   已经平滑成功。

短接近桥段可能本来就是最小 jerk 曲线，但接入静止保持时仍有 jerk
阶跃。此时允许归一化 jerk 能量增加不超过 20%、归一化加速度总变化
增加不超过 10%，以换取端点连续性，报告标记为 `boundary_continuity`，
不宣称这类段降低了能量。其他通过候选要求归一化 jerk 能量降低至少 2%。

平顺度报告包含加速度总变化 `integral |jerk| dt`、jerk 总变化（包含
连接处跳变以及进入/退出静止保持的跳变）、积分平方 jerk 以及最大 jerk 跳变。各关节求和指标用于
同一任务的版本对比，不是物理安全阈值。

为了不把单纯放慢当成路径变好，选型还使用统一缩放不变的指标：
`T^5 * integral jerk^2 dt`、`T^2 * acceleration_total_variation`、
`T^3 * jerk_total_variation`。显示的时间与实际变化量仍保留，不能只报
一个有利的归一化值。

## 本地录制数据结果

同一 jerk=5 软件策略、速度倍率 1；时间单位秒。加速度总变化是所有
关节的解析积分指标，不是实际电机测量，也不等于主观卡顿降低比例。

| 轨迹 | V3 最快 | V4 平顺 | 加速度总变化降低 |
| --- | ---: | ---: | ---: |
| 左拨 v7 | 45.084 | 40.207 | 41.5% |
| 完整右拨 v9 | 38.113 | 41.219 | 33.2% |
| 当前选中右拨 v1 | 39.236 | 40.844 | 40.0% |
| 拉环组合 | 77.197 | 82.883 | 40.9% |
| 起落杆组合 | 62.872 | 68.465 | 35.6% |
| 滑轨接近 A | 11.286 | 11.889 | 50.2% |
| 滑轨接近 B | 25.981 | 29.379 | 81.1% |
| 滑轨退出 A | 6.972 | 6.939 | 77.7% |

完整右拨 v9 在 jerk=10 下是 31.498 -> 35.280 秒，加速度总变化降低
38.7%。这轮是平顺候选，不是所有轨迹同时提速。通过的候选内部 jerk
跳变量约 0.00004~0.00022 rad/s^3，最终 V/A/J 仍按输出多项式检查。

起落杆单独 `above_to_lower` v6 与 `upper_to_above` v5 暂未找到满足全部
选型约束的结果，分别保留 V3 的 6.659 秒和 9.335 秒候选。这两个单段
仍有原有 jerk 跳变，不能将“组合已改善”理解为它们也已改善。组合的
业务单元范围与单独片段不同，因此拟合结果也不同。

数据文件：`data/composition_candidates/*-v4-extra0.15-evidence.json`。
保留 `original`、`baseline`、`candidate`、`smooth` 四种版本；没有修改
当前生产录制选择，没有推送 Jetson。

## 面板与播放

在离线编辑器的“优化对比”页启用“生成平顺优先候选”。原路径、V3
最快候选与 V4 平顺候选并存。增加单关节带正负号的速度、加速度、jerk
曲线，避免把“各关节绝对值最大”包络的切换当成某一关节的抖动。

同时修正组合预览附加手指状态时清空手臂导数的问题：现在保留手臂
q/v/a，手指等待段仅在可视化中使用一秒五次平滑过渡。不是对真实手指
响应的测量，也没有修改真机手指控制。不能把规划曲线画得平滑、实际
离线播放却改成分段线性运动。

验证：完整回归 68 项通过；补强手臂 q/v/a 保留和四候选/单关节曲线
测试后，面板相关 20 项再次通过。重启离线服务后，在 localhost-only
ROS domain 89 播放起落杆平顺组合，6 秒窗口收到 181 个关节状态和
181 个预览 TF 消息，接收频率约 30.04 Hz，右肩俯仰位置变化范围
0.810 rad。它验证的是可视化数据持续变化，不是 GPU 帧率或真实机器人
运动。截图：`data/trajectory_edit_audit/screenshots/offline_optimizer_v4.png`。

## 边界

- jerk=5/10/20 仍是离线软件策略；本轮没有新增任何电机能力证明。
- 混合接触/接近单元的 V4 拟合保守地采用整单元最严格的容差。独立
  接近/退出单元仍可使用较宽容差。
- 滑轨候选仍是关节路径实验，没有替换生产接触 TCP 速度策略。
- 本轮不证明全局最优、无碰撞或实物接触安全；更大幅度改变接触路径
  需要关键点、物体约束或重复示教数据。

## 固定预览与任务切换

离线编辑器的“优化对比”页现在按“任务 / 当前选中单段”自动加载已保存
结果。无需点击生成；没有匹配结果时不会悄悄重新规划或代用其他录制。
修改参数后仍需明确重新生成，新结果会自动保存。

- 文件在 `data/offline_optimizer_previews/`，每份结果有 SHA256 校验、
  模型校验、实际使用的轨迹版本、参数、组合顺序、完整候选和曲线数据。
- 切换任务只恢复保存的结果，不调用优化器。启动默认加载最近生成的
  任务；当前准备的默认任务为起落架组合。
- 单段检查当前选中版本和内容；起落架组合检查录制内容；拉环组合检查
  截尾版本及原退出父版本。发生变化时明确拒绝加载旧结果。
- 起落架这份 V4 组合为 **68.464808195 秒**：jerk=5、速度倍率=1、
  完整往返=1、LOWER 起始、UPPER 结束、含退出，即下→上→下→上。
  它不是一次单向上杆，也不是独立“组合预览”页的旧算法结果。
- 尚不能确定用户之前看到的 70.38 秒对应哪次计算；不把不同页面、
  版本或参数的时长差异当成新的优化效果。

此轮预载仍是已验证的 V4 候选，不宣称删除断点的停顿已消除。检查已
确认 V4 跟随旧时间轴进行拟合，可能保留内部低速谷；拉环独立单元边界
也仍有停稳约束。空间进度重建试验尚未同时满足偏差与时长要求，没有
接入面板或替换这些固定预览。后续真正通过验证的新算法结果需要更新
对应快照，才能避免把界面更新误当作轨迹优化。

后续 V5 已加入局部内部停顿修整并另存候选，参见同目录的
`INTERNAL_STOP_OPTIMIZATION_V5.md`。V4 保持为独立对照，不覆盖其历史结果。
